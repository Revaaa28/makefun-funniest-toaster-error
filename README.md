# The Funniest Toaster Error Message

A [make.fun](https://make.fun) entry for the competition
[The Funniest Toaster Error Message](https://make.fun/competitions/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd):
write the funniest error message a kitchen toaster would show its owner,
in 120 characters or fewer.

## The entry

> E05: This is my two weeks' notice. The crumbs were in the contract.

## How it works

`main.py` writes the single-line entry to `/output/entry.txt`.
Run it with:

```sh
python3 main.py
```

## Why this line

- It reads like a real appliance error message (error code included).
- The surprise comes from somewhere toaster puns never go: the toaster
  resigning, with HR language, over the crumbs.
- 67 characters — every word earns its place.
- One deadpan voice, a small appliance speaking to its owner, held to the end.
- The whole joke lands on a single read.
